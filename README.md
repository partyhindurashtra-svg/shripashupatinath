# Shri Pashupatinath Dham, Hassangarh

Official website of **Shri Pashupatinath Dham** — a sacred temple of Lord Shiva (Pashupati) at
**Hassangarh, Sampla, District Rohtak – 124404, Haryana, India**.

🌐 **Live site:** https://shripashupatinath.com

The dham is inspired by the holy **Pashupatinath Mandir of Kathmandu, Nepal**, from where the
sacred **Shivling** was brought.

## About the site

A static, dependency-free website (HTML/CSS/vanilla JS) hosted on GitHub Pages.

- `index.html` — main site: about, significance & mantras, the Kathmandu connection,
  the annual Bhandara (free community feast every **30th November**), the Param Sewak Board,
  a darshan gallery, and contact.
- `making.html` — *“The Making of the Dham”*: the construction journey, a timeline and a
  construction-photo gallery.
- A continuously looping devotional **mantra audio** and a scrolling mantra marquee run across
  the site.

## Structure

```
index.html          Main page
making.html         "The Making of the Dham" page
css/styles.css      Theme
js/script.js        Gallery, lightbox, nav, looping audio
assets/
  gallery/          Temple photographs (temple-01 … temple-30)
  om-namah-shivaya.ogg   Looping prayer audio
  om-chant.wav           Fallback "Om" drone
  dr-kk-saini.png        Portrait of Prof. Dr. K. K. Saini
CNAME               Custom domain (shripashupatinath.com)
```

## Deployment

Served via **GitHub Pages** from the `main` branch. The `CNAME` file maps the custom
domain `shripashupatinath.com`.
